# Product Backlog

Backlog produit de LONTANO. Chaque User Story validée possède un fichier dédié dans
[`../user-stories/`](../user-stories/README.md) et reste la **source unique** de ses
règles et critères d'acceptation. Ce backlog n'en donne qu'une vue d'ensemble.

## Légende des statuts

| Statut | Signification |
|--------|---------------|
| `Draft` | En cours de rédaction / discussion |
| `Validated` | Validée par le Product Owner |
| `Ready` | Prête à être développée (après GO applicatif du PO) |
| `In progress` | En cours de développement |
| `Done` | Livrée |

> Le PO a donné le GO MVP : le développement est lancé, focalisé sur US-01. Les US
> suivantes restent à démarrer uniquement après validation du checkpoint US-01.
